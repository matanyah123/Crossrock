# About

Crossrock is a Fabric mod that brings Bedrock Edition resource packs and add-ons to Java Edition through automatic, real-time translation.

To add a pack, just drag & drop onto the dedicated pack window, enable the pack or add-on, and apply the resource pack in the native resource packs section (only needed once).

---

Crossrock is designed to be neutral: installing the mod by itself changes nothing. Bedrock compatibility is only activated when a Bedrock pack provides content to replace or extend vanilla resources.

# Alpha

Crossrock is currently in alpha. Many Bedrock features already work, but full Add-On compatibility is still a work in progress. Some packs or individual features may render incorrectly or not work yet.
